# Original Data-Pipeline Asset Sources

The second TNO manual informed the intelligence-receiving-terminal concept: radio equipment represents collection, the stage table represents processing, and logs represent received records.
All assets below were decoded from the user-supplied local mod DDS files, not generated by AI. Original colors, transparency, and proportions are retained; political emblems are not repurposed.

Buttons retain the original texture and hard-edged outline. Progress bars indicate processing stages already reached, without pretending to estimate remaining time.
Checkboxes follow noOfFrames=2 in interface/frontendgamesetupview.gfx and use 28×23 frames.
English labels/readings reuse Aldrich TNO. Chinese headings reuse the existing Ruizhenghei subset; long logs use a system monospace font for readability.
Both failure and recovery states are retained. Original photographs receive no uniform green filter. Full logs can be toggled; machine-event lines are hidden by default while diagnostic text remains visible.
